## Rota Itacajá

Na data deste snapshot **nenhum ponto da Rota Itacajá havia sincronizado**. O
último ponto recebido pelo repositório é de 31/08/2026 17:28, da Presidente
Kennedy. A rota foi encerrada a pedido da supervisão; os pontos que estiverem
no aparelho continuam podendo subir depois — cada ponto carrega o nome do
projeto gravado no momento da coleta, então chegam como "Rota Itacajá" mesmo
com outra rota ativa. Quando isso acontecer, vale refazer o snapshot.

Essa branch não deve ser removida. Ela existe para impedir que os dados
históricos sejam apagados por novas sincronizações com a mesma numeração local.
